# Talking points

My chapter is about patterns and anti-patterns, so I started by searching academic literature and technical papers for such patterns.

In total I found around 50, I've divided them into different categories, depending on which kind of problem they discuss.

The categories are:
 * Communication
 * Data management/handling
 * Parallelism
 * Orchestration of software
 * Execution ordering
 * Some miscellaneous patterns and anti-patterns

For each of these categories I've further divided the larger categories into subcategories and  written about what the commonalities are.

For example, in patterns talking about network communication, the requests themselves seem to be the biggest performance issue, while for communication within a single system, the data within the requests become much more important.

One problem I have is that while I found 8 quite relevant sources discussing specifically patterns and anti-patterns within the field, only one of them gives explanations for the meaning of the patterns they describe, while the other 7 only describe anti-patterns.

Thankfully that one source for patterns talks about ~20 different patterns, but still...
